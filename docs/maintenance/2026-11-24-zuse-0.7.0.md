# Zuse v0.7.0 发布与依赖回执

正式版 `v0.7.0` 由源码 `8823323e97f2106074ce73e7d192544cbf00db33` 构建。Linux 和 macOS 各有 x86-64 与 ARM64 下载包，Windows 有 x86-64 下载包。已下载全部五个包，与 GitHub 记录的字节数和 SHA-256 逐一核对。Linux x86-64 压缩包的 SHA-256 是 `c058dc37a0cd0c3f6cfd55d4b3d09bfb680bd0c7c649a1fd3f78652f6fd2a7f7`。正式版 Rust 测试 498 项通过，22 项忽略，Clippy 通过。[正式版](https://github.com/LIghtJUNction/zuse/releases/tag/v0.7.0) · [构建记录](https://github.com/LIghtJUNction/zuse/actions/runs/45414708147)

后续源码 `2228f9318d167435c354bfacef889dc0df58c09b` 增加 `zuse mcp serve` 别名，以及 Codex、Claude Code、SSMCP 快捷安装和预览。500 项 Rust 测试通过，22 项忽略。12 项 MCP 传输测试、Clippy 和 wasm32 无标准库检查通过。Codex 和 Claude Code 的隔离配置通过首次安装、重复安装和已有条目冲突测试。SSMCP 通过实际下载和安装测试，在 PATH 中存在独立版 Zuse 时重复执行也复用同一托管安装。[快捷安装源码](https://github.com/LIghtJUNction/zuse/commit/2228f9318d167435c354bfacef889dc0df58c09b)

本机 SSMCP 托管安装的 Linux x86-64 可执行文件与发布包内容一致，SHA-256 是 `c0706d63986affb60d52d6360b051dc27d5ea86efb11acfe666996209a053933`。Codex 和 Claude Code 的用户配置均已由 `linux-computer-use` 切换到该文件的原生 stdio 服务。两份配置均通过读回、初始化与十项工具发现验收。新会话加载新配置。
